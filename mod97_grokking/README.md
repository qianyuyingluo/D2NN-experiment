# 模 97 加法 D2NN / grokking 实验

## 在 IDLE 中运行

1. 使用安装了 numpy、torch、matplotlib 的 Python/IDLE。
2. 打开 `generate_data.py`，按 F5，生成 `mod97_data.npz`。
3. 打开 `train.py`，按 F5，启动训练。缺少数据时也会自动生成。

路径均以脚本位置为基准，不需要改变工作目录。每次训练新建 `runs/时间戳/`，不覆盖旧实验。默认不恢复训练。Ctrl+C 可中断并保存当前权重；IDLE 强制重启或终止进程则只能保留上次保存结果。

数据：全部 97×97=9409 个有序数对，输入 a,b∈[0,96]，输出 (a+b)%97。默认固定随机种子 42，50% 训练、50% 测试。有序数对随机拆分，交换顺序的样本可能分布在两侧。更改比例和种子后，重新运行生成脚本。训练时验证标签和划分完整性。

这是模加法分类任务，没有时序状态；若作累加计数器，需要外部保存上次结果，并把它和本次增量作为下一次输入。

## 网络与参数

保留原项目的相位调制、角谱传播和探测器能量分类思想，重新训练一个独立模型，不使用 MNIST 权重。两个数分别编码到两个 10×10 空间区域的单个亮点，不使用标签构造输入。五层 64×64 相位板，上采样到 128×128 光场，传播 FFT 使用两倍零填充。输出是 97 个不重叠的 6×6 探测区域，按能量最大值分类。与 MNIST 实验相比，光场网格和探测器布局已改变。

`train.py` 顶部可改 EPOCHS（默认 10000）、BATCH_SIZE（32）、LEARNING_RATE（0.001）、WEIGHT_DECAY（0.01）、EVAL_EVERY（10）、SAVE_EVERY（100）。优先使用 CUDA，否则 CPU。先根据前几轮耗时判断长期运行成本，显存不足则降低 batch size。

每次评估使用同一时刻模型测量完整训练集和测试集。打印本段墙钟时间、累计纯训练时间、总时间（含评估/保存等）。CSV 记录实际时间；曲线横轴为 epoch。不按测试成绩挑选最佳权重，也不因训练集拟合完成提前停止。每 100 epoch 保存 `last.pt` 和曲线；最终及正常捕获中断时也保存。运行目录留存配置、精确数据划分、metrics.csv、summary.json。

## 如何观察 grokking

观察是否先出现训练准确率接近 100%、测试准确率长期较低，随后测试准确率显著提升。随机猜测约为 1/97=1.03%。summary.json 中的首次 99% 阈值轮次只是辅助记录，受评估间隔限制，不能单独证明 grokking。未到 99% 记为 null。

本实验是纯相位 D2NN 的探索，不是原论文 Transformer 的复现。线性光场传播加最终强度读出具有结构约束，可能连训练集也无法完全拟合；这种情况不能称为“尚未等到 grokking”。相位衰减也不等同于普通网络的权重范数正则化。不要承诺一定发生；应结合完整曲线，并用多个种子复查。未观察到时只说明本次配置和训练预算下未观察到。
